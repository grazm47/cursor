# Ассистент по продаже сетки-рабицы (оцинкованная)

Мини‑веб‑приложение с чат‑ботом для расчёта и оформления предложения по сетке‑рабице из оцинкованной проволоки.

## Запуск

1) Установите зависимости:

```bash
pip install -r requirements.txt
```

2) Запустите сервер разработки:

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

3) Откройте браузер:

```
http://localhost:8000
```

## Настройка цен

Измените `app/config/pricing.json` под ваши цены, условия и ассортимент:
- `base_price_per_m2`: базовая цена за м² для ячейки 50 мм и проволоки 2.5 мм
- множители для `wire_diameter_multipliers`, `cell_size_multipliers`, `coating_multipliers`
- длина рулона `roll_length_m`
- доставка `shipping`
- комплектующие `accessories`

Цены примерные и служат шаблоном. Проверьте и скорректируйте под ваш прайс.

## Возможности
- Пошаговый сбор параметров: высота, длина, ячейка, диаметр, покрытие
- Автоподсказки и быстрые ответы
- Расчёт количества рулонов, площади и стоимости
- При желании — расчёт доставки
- Сохранение простой сессии в памяти процесса

## Важно
- Приложение хранит состояние в памяти процесса и не предназначено для продакшена без внешнего хранилища.
- Все расчёты упрощены и зависят от конфигурации. Проверьте результаты перед использованием в коммерческих предложениях.
