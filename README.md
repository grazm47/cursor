# Ассистент по продаже сетки рабицы

Современное веб-приложение для помощи в выборе и расчете стоимости сетки рабицы из оцинкованной проволоки.

## 🚀 Возможности

- **Калькулятор стоимости** - точный расчет необходимого количества и стоимости сетки
- **Каталог продукции** - подробное описание различных типов сетки с фильтрацией
- **Консультации** - форма обратной связи для получения профессиональной помощи
- **Адаптивный дизайн** - отлично работает на всех устройствах
- **Современный интерфейс** - интуитивно понятный и красивый дизайн

## 🛠 Технологии

- React 18
- React Router для навигации
- Vite для сборки
- Lucide React для иконок
- CSS Grid и Flexbox для верстки

## 📦 Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите проект в режиме разработки:
```bash
npm run dev
```

3. Откройте браузер и перейдите по адресу:
```
http://localhost:3000
```

## 🏗 Сборка для продакшена

```bash
npm run build
```

## 🎯 Основные функции

### Калькулятор
- Расчет площади и стоимости сетки
- Выбор размера ячейки (25x25 до 100x100 мм)
- Выбор диаметра проволоки (1.6 до 3.0 мм)
- Учет количества рулонов

### Каталог
- 6 типов сетки рабицы
- Фильтрация по категориям
- Поиск по названию и описанию
- Детальные характеристики каждого типа

### Контакты
- Форма обратной связи
- Контактная информация
- Информация о компании

## 🎨 Дизайн

Приложение использует современный минималистичный дизайн с:
- Четкой типографикой (шрифт Inter)
- Приятной цветовой схемой
- Анимациями и переходами
- Адаптивной версткой

## 📱 Адаптивность

Приложение полностью адаптировано для:
- Десктопов (1200px+)
- Планшетов (768px - 1199px)
- Мобильных устройств (до 767px)

## 🔧 Настройка

Для изменения контента отредактируйте соответствующие файлы:
- Цены и характеристики - `src/pages/Calculator.jsx` и `src/pages/Catalog.jsx`
- Контактная информация - `src/pages/Contact.jsx`
- Общая информация - `src/pages/Home.jsx`
