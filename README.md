# 🤖 Ассистент-продавец с GigaChat

Интеллектуальный ассистент-продавец для интернет-магазина, использующий нейросеть GigaChat для общения с покупателями в терминале.

## 🚀 Возможности

- **Интеллектуальное общение**: Использует GigaChat для естественного диалога
- **Каталог товаров**: Встроенная база данных товаров с поиском
- **Акции и скидки**: Информация о текущих предложениях
- **Интерактивный интерфейс**: Удобное общение в терминале
- **История разговора**: Сохранение контекста диалога
- **Специальные команды**: Быстрый доступ к функциям

## 📋 Требования

- Python 3.7+
- Интернет-соединение
- API ключ GigaChat

## 🛠 Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd sales-assistant
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте API ключ (уже настроен в коде):
```python
# В config.py или в коде
GIGACHAT_API_KEY = "ваш_api_ключ"
```

## 🎯 Использование

### Базовый ассистент
```bash
python sales_assistant.py
```

### Расширенный ассистент (рекомендуется)
```bash
python advanced_sales_assistant.py
```

## 📖 Команды и функции

### 🔍 Поиск и каталог
- `показать смартфоны` - показать все смартфоны
- `показать ноутбуки` - показать все ноутбуки
- `показать наушники` - показать все наушники
- `найти [товар]` - поиск конкретного товара
- `информация о [товар]` - подробная информация о товаре

### 💰 Акции и цены
- `акции` - показать текущие акции
- `скидки` - показать скидки
- `цены` - показать цены на товары

### 📦 Заказ и доставка
- `как заказать` - информация о заказе
- `доставка` - информация о доставке
- `оплата` - способы оплаты
- `возврат` - условия возврата

### ❓ Помощь
- `помощь` - показать справку
- `выход` - завершить работу

## ⚙️ Настройка

### Изменение API ключа
Отредактируйте файл `config.py`:
```python
GIGACHAT_API_KEY = "ваш_новый_api_ключ"
```

### Добавление товаров
В файле `advanced_sales_assistant.py` найдите словарь `products_db` и добавьте новые товары:
```python
self.products_db = {
    "ваша_категория": [
        {
            "name": "Название товара",
            "price": 10000,
            "description": "Описание товара",
            "stock": 5
        }
    ]
}
```

### Настройка промпта
Измените `SYSTEM_PROMPT` в `config.py` для настройки поведения ассистента.

## 🔧 Устранение неполадок

### Ошибка подключения к API
- Проверьте интернет-соединение
- Убедитесь в правильности API ключа
- Проверьте доступность сервиса GigaChat

### Ошибки SSL
- В коде отключена проверка SSL для тестирования
- Для продакшена рекомендуется настроить SSL сертификаты

### Проблемы с кодировкой
- Убедитесь, что терминал поддерживает UTF-8
- Используйте Python 3.7+ для корректной работы с эмодзи
