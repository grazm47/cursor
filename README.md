### Терминальный ассистент‑продавец на базе GigaChat

Минималистичный CLI, который ведёт диалог с покупателем через API GigaChat.

#### Быстрый старт

1) Создать и активировать виртуальное окружение, установить зависимости:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

2) Указать API‑ключ для GigaChat (строка для заголовка `Authorization: Basic ...`). Удобнее всего через переменную окружения:

```bash
export GIGACHAT_API_KEY="<ВАШ_API_KEY>"
```

Дополнительно можно задать:
- `GIGACHAT_SCOPE` (по умолчанию `GIGACHAT_API_PERS`)
- `GIGACHAT_MODEL` (по умолчанию `GigaChat`)
- `SALES_ASSISTANT_SYSTEM_PROMPT` для изменения роли ассистента

3) Запустить ассистента:

```bash
python -m sales_assistant
```

Команды во время диалога:
- `/reset` — очистить контекст
- `/exit` — выйти
- `/help` — краткая справка

Если в вашей среде возникают проблемы с сертификатами TLS, можно временно отключить проверку цепочки:

```bash
python -m sales_assistant --insecure
```

#### Пример системного промпта

```text
Ты — вежливый и проактивный ассистент‑продавец. Отвечай кратко и по делу на русском языке. Уточняй потребности, предлагай подходящие товары, объясняй выгоды простыми словами, предлагай следующий шаг (добавить в корзину, оформить заказ, показать ещё варианты). Если чего-то не знаешь — скажи честно и предложи альтернативу. Не придумывай фактов. Для восприятия используй маркированные списки, когда это уместно.
```

#### Параметры запуска

```bash
python -m sales_assistant --help
```
