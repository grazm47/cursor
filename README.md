# 🛍️ Ассистент-Продавец с Гигачат

Интеллектуальный ассистент-продавец для магазина электроники, использующий нейросеть Гигачат от Сбера.

## 🚀 Возможности

- 💬 Интерактивное общение с покупателями в терминале
- 🔍 Помощь в выборе товаров и сравнении характеристик
- 🎨 Красивый цветной интерфейс в терминале
- 📚 Сохранение истории разговора
- 🤖 Использование API Гигачат для генерации ответов

## 📋 Требования

- Python 3.7+
- API ключ Гигачат
- Интернет-соединение

## 🛠️ Установка

1. **Клонируйте репозиторий или скачайте файлы:**
   ```bash
   git clone <ваш-репозиторий>
   cd <папка-проекта>
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройте API ключ:**
   - Убедитесь, что файл `.env` содержит ваш API ключ Гигачат
   - Формат: `GIGACHAT_API_KEY=ваш_api_ключ`

## 🎮 Использование

### Запуск ассистента:

**Linux/macOS:**
```bash
./run.sh
```

**Windows:**
```cmd
run.bat
```

**Или вручную:**
```bash
# Создайте и активируйте виртуальное окружение
python3 -m venv venv
source venv/bin/activate  # Linux/macOS
# или
venv\Scripts\activate     # Windows

# Установите зависимости
pip install -r requirements.txt

# Запустите ассистента
python sales_assistant.py
```

### Команды управления:

- `выход`, `quit`, `q` - завершить работу
- `очистить`, `clear`, `c` - очистить историю разговора
- `помощь`, `help`, `h` - показать справку по командам

### Примеры вопросов:

- "Посоветуй хороший смартфон до 50000 рублей"
- "Какие характеристики у iPhone 15?"
- "Сравни Samsung Galaxy S24 и Xiaomi 14"
- "Что лучше для игр - ноутбук или ПК?"

## 🔧 Технические детали

### Основные компоненты:

1. **SalesAssistant** - главный класс приложения
2. **GigaChatClient** - клиент для работы с API Гигачат
3. Цветной интерфейс терминала с помощью `colorama`
4. Обработка ошибок и валидация ввода

### API Гигачат:

- Аутентификация через OAuth 2.0
- Автоматическое получение и обновление токенов
- Поддержка истории разговора
- Настроенные параметры для роли продавца

## 🎯 Особенности

- **Контекст продавца**: ИИ настроен как дружелюбный продавец-консультант
- **История разговора**: Сохраняется до 20 последних сообщений
- **Обработка ошибок**: Graceful handling сетевых и API ошибок
- **Удобный интерфейс**: Цветная подсветка и эмодзи для лучшего UX

## 🚨 Устранение неполадок

### Ошибки API:
- Проверьте правильность API ключа в `.env`
- Убедитесь в наличии интернет-соединения
- Проверьте квоты на использование API Гигачат

### Ошибки установки:
```bash
# Обновите pip
pip install --upgrade pip

# Переустановите зависимости
pip install -r requirements.txt --force-reinstall
```
