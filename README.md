# Ассистент по продаже сетки рабица "СетКомПлюс"

Веб-приложение для продажи оцинкованной сетки рабица с интерактивным калькулятором стоимости и чат-ботом для консультации клиентов.

## Функциональность

### 🏠 Главная страница
- Современный дизайн с градиентами и анимациями
- Информация о преимуществах оцинкованной сетки рабица
- Быстрый доступ к каталогу и калькулятору

### 📦 Каталог продукции
- 4 основных типа сетки с разными размерами ячеек:
  - 25×25 мм - для курятников и мелких животных
  - 35×35 мм - для вольеров
  - 50×50 мм - универсальная для заборов
  - 60×60 мм - экономичная для больших участков
- Визуализация сетки с помощью SVG
- Детальные характеристики каждого типа

### 🧮 Калькулятор стоимости
- Интерактивный расчет стоимости в реальном времени
- Параметры для расчета:
  - Размер ячейки (25-60 мм)
  - Высота сетки (1.0-2.0 м)
  - Длина (произвольная)
  - Диаметр проволоки (1.4-2.5 мм)
- Автоматический расчет площади и общей стоимости
- Учет коэффициентов для разных диаметров проволоки

### 💬 Чат-бот консультант
- Интеллектуальная система ответов на основе ключевых слов
- Помощь в выборе подходящего типа сетки
- Консультации по применению (забор, курятник, вольер, дача)
- Информация о ценах, доставке и качестве

### 📋 Система заказов
- Модальные окна для оформления заказа
- Автоматическое заполнение данных из калькулятора
- Форма с контактными данными и адресом доставки
- Сводка заказа с детальной информацией

### 📱 Адаптивный дизайн
- Полная поддержка мобильных устройств
- Отзывчивая верстка для всех размеров экранов
- Оптимизированный интерфейс для планшетов

## Запуск приложения

### Простой запуск
1. Откройте файл `index.html` в любом современном веб-браузере
2. Приложение готово к использованию!

### Запуск с локальным сервером (рекомендуется)
```bash
# Используя Python 3
python -m http.server 8000

# Используя Node.js (если установлен npx)
npx serve .

# Используя PHP
php -S localhost:8000
```

Затем откройте http://localhost:8000 в браузере.

## Особенности реализации

### Ценообразование
Система динамического ценообразования учитывает:
- Базовую цену в зависимости от размера ячейки
- Коэффициенты для разных диаметров проволоки
- Автоматический пересчет при изменении параметров

### Чат-бот
Простая но эффективная система обработки запросов:
- Поиск ключевых слов в сообщениях пользователя
- Контекстные ответы для разных сценариев использования
- Возможность легкого расширения базы знаний

### UX/UI решения
- Плавные анимации и переходы
- Интуитивная навигация
- Визуальная обратная связь для всех действий
- Оптимизированная типографика и цветовая схема
