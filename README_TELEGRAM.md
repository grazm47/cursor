- **Каталог товаров** с ценами и описаниями
- **Оформление заказов** через бота
- **Информация об акциях** и скидках
- **Контакты компании**
- **Автоматические ответы** на вопросы
- **Отправка заявок** на email

2. Бот запрашивает имя
3. Бот запрашивает телефон
4. Бот запрашивает адрес доставки
5. Бот запрашивает количество товара
6. Заказ оформляется и отправляется на email

- Доставке

## 🔧 Настройка

### Изменение токена бота
Отредактируйте строку в `telegram_bot.py`:
```python
BOT_TOKEN = "ваш_новый_токен"
```

### Изменение email для заявок
Отредактируйте в классе `TelegramSalesAssistant`:
```python
"order_email": "ваш_email@example.com"
```

### Добавление новых товаров
Добавьте товар в словарь `products_db` в методе `__init__`:
```python
"новый_товар": {
    "name": "Название товара",
    "price": 1000,
    "description": "Описание товара"
}
```

## 🚀 Запуск в продакшене

### Рекомендации для продакшена:
1. Используйте виртуальное окружение
2. Настройте логирование
3. Добавьте обработку ошибок
4. Настройте отправку email
5. Используйте supervisor или systemd для автозапуска

### Пример запуска через supervisor:
```ini
[program:telegram_bot]
command=/path/to/venv/bin/python /path/to/telegram_bot.py
directory=/path/to/project
user=www-data
autostart=true
autorestart=true
stderr_logfile=/var/log/telegram_bot.err.log
stdout_logfile=/var/log/telegram_bot.out.log
```
